### What is TailwindCSS?
==> TailwindCSS is a popular utility-first CSS framework that provide a set of pre-built CSS classes, you can use to build user interface.
### What is Utility-first approach?
==> Utility-first approach: Tailwind CSS promotes a utility-first methodology, where you build your user interface by applying small utility
    classes directly to the HTML elements.
### There are many ways to install TailwindCSS framework:
    1. Install using CLI
    2. Using CDN
    3. others
### Key Features
- Utility-first approach
- Comprehensive set of utility classes
- Customizable and extensible
- Responsive design support
- Integration with JavaScript frameworks
- Purge CSS for optimized production builds
### 3 layers of tailwindCSS framework
- @layer base
- @layer utilities
- @layer component
